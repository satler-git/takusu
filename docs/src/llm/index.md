# LLM / Agent 向け

このセクションは、**takusu-agent** が提供するツール定義だけでは補足しきれない概念や注意点を説明する。

「takusu-agent」はローカルサーバーまたは Worker に接続し、タスク、習慣、スケジュールを操作するためのツールを提供する。
ツール名、引数、型はツール定義に含まれている。
ここでは、ツール定義に収まらない以下のような詳細を扱う。

- **ツールの可視性**：Direct と Deferred、`tool_search` での発見
- **タスク参照**：`#42` や `h1#3` の読み方と正規化
- **日時表現**：サーバー timezone で解釈される相対表現
- **承認フロー**：永続的な変更が `ProposedChange` として提案される仕組み
- **習慣の steps と scheduled spans**：スキーマだけでは伝わらない更新ルール
- **検索クエリの構文**：`list_tasks` や `memory_search` で使う修飾子
- **繰り返しルール**：RFC 5545 RRULE のうち有効な部分と検証方法

ページはドメイン別に分けている。
個別のツール引数を探す場合は、「takusu-agent」のツール定義を確認する。
