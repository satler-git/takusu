# 曖昧な入力の確認

`correct_asr` は Direct ツールである。

`correct_asr` は、音声認識の結果が曖昧な場合にユーザーに確認を求めるツールである。

## 使いどころ

以下のような曖昧さが文脈だけでは解決できないときに使う。

- 固有名詞
- 同音異義語
- 数値
- 日時、曜日
- アクション対象

明らかな ASR エラーは文脈から推測して修正する。
過剰な確認を増やさないよう注意する。

## 質問のまとめ方

複数の質問は 1 回の呼び出しにまとめる。
各質問は `text`（認識されたテキスト）と `for`（何のために使い、なぜ曖昧か）を含める。

```json
{
  "questions": [
    {
      "text": "こうれい",
      "for": "「高麗」か「校令」か曖昧です。どちらの漢字ですか？"
    }
  ]
}
```
