# コンセプト

takusu を使うときに扱う概念を整理します。

- **[タスク](task.md)**：やること。
- **[習慣](habit.md)**：繰り返し発生する予定。
- **[スケジュール](schedule.md)**：タスクや習慣を時間軸に並べた結果。
- **[Solver](solver.md)**：スケジュールを作る計算エンジン。
- **[カレンダー連携](calendar-sync.md)**：Google Calendar や iCal との連携。
- **[音声アシスタント](voice-assistant.md)**：録音からテキスト化し、テキストを音声で応答する対話 UI。

全体として、takusu は「タスク」と「習慣」を扱うモデル、「自動スケジューリング」、および「音声での操作 UI」で構成されています。
