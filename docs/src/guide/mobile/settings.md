# 設定

設定はカテゴリ別のページに分かれています。

## General

General 設定は、外観と同期に関する項目です。

- ダークテーマとライトテーマ
- 同期設定

## Worker

Worker 設定は、「Cloudflare Worker」への接続情報です。

- エンドポイント URL
- API トークン

## Google Calendar

Google Calendar 設定は、「Google Calendar」連携と同期対象カレンダーです。

- 連携設定
- 同期対象カレンダー

## Info

Info ページは、アプリの情報を表示します。

- ライセンス
- バージョンとビルド番号
