# ホーム画面

ホーム画面は、タスクを時系列順に表示するメイン画面です。

## 構成

ホーム画面は上段、中段、下段の 3 つの領域で構成されています。

- **上段**：ハンバーガーメニュー、検索ボタン、同期ボタン
- **中段**：タスクカードのリスト
- **下段**：タスク追加ボタン、タスク実行開始/Done ボタン

## タスクカード

タスクカードは、時刻、タイトル、所要時間、**`abandonability`** などで構成されています。
**`abandonability`** は、タスクを中断しやすさを示すパラメータです。
所要時間は平均（avg）と標準偏差（σ）の 2 つの値で表します。

- **左側**：開始時刻と終了時刻
- **中央**：タイトル
- **背景色**：「`abandonability`」の値に応じた色
- **右下**：所要時間（avg, σ）

## 操作

タスクカードに対する操作は以下の通りです。

- **タップ**：タスク詳細画面へ遷移
- **長押し**：選択モード
- **右スライド**：Done
- **左スライド**：削除
- **長押し＋ドラッグ**：タスクの順序を調整

## グルーピング

タスクは状態と日付に応じてグループ化されます。

- **`pending` のタスク**：上部に表示
- **日付が変わるごと**：区切り線を表示
- **過去のタスク**：上に引っ張ると表示
