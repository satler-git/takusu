v7: レイアウト整理（2026-07-27）

  • hero の情報を絞った: タイトル + ステータス pill + 説明 + 進捗バーに集約。時刻・RRULE 要約は専用セクションに委ね、情報の被りを減らした。
  • Status pill を右寄せ: .hero-meta を justify-content: space-between にし、ステータス pulldown を右端に配置。
  • 説明は hero 直下: 独立した説明カードを廃止し、hero 内またはタイトル入力の直下に置いた。
  • add ボタンを full-width: 「依存を追加」「休止期間を追加」「ステップを追加」をセクション幅いっぱいに。
  • 休止/アクティブ期間を view から編集: 追加・削除ボタンを view モードにも配置。
  • edit 時は依存グラフを非表示: view のみ表示。
  • ステップ表示を整理: 時間軸 timeline（.step-track）を廃止し、依存関係は .step-deps で独立表示。accordion unfold 時はヘッダーから時刻を消し、fold 時のみ表示。
  • bool 編集を switch に統一: 並列実行 / 並列受け入れ / 時間固定 / アクティブは switch。依存だけ checkbox。
  • sigma 未入力は placeholder: 「1m (avg/5)」を placeholder 表示。window ヒントを削除。
  • maximize ボタン: 44px に拡大、センタリング。

v6: 見づらさの修正

  • ヘッダーに要約を集約: タイトル + ステータス pill + 進捗バー + 説明を 1 枚の hero にまとめた。スクロールせずに「今どうなっているか」が分かる。
  • 無題カードの廃止: 全セクションに見出し（操作 / 見積もり / 関連 / 説明 / 依存）を付け、件数は右肩に置いた。帯の羅列に見えなくなる。
  • 操作ボタンの整理: v5 は「一時停止」が 2 行に折り返し、primary（緑の完了・紫の記録）が 2 つあった。v6 は 記録 のみを塗り potential とし、停止 / 分割 / 完了は同じ重みのアウトラインに統一。ラベルを短くして 1 行に収めた。数量の増減は stepper に統合。
  • 同語反復の除去: 「並列実行 → 並列で実行」のような重複行をやめ、3 つの真偽値を chip 1 行に圧縮（on は tint、off はグレー枠）。4 行が 1 行になった。
  • 意味のない色の除去: 「並列で実行」の緑を廃止。緑は完了系にのみ使う。
  • 用語: abandonability → 「放棄しやすさ」。値は「標準 0.50」のように意味を主、数値を従にした。
  • 依存グラフ: v5 の「3 ノード横一列」は実物と違う。実際は components/graph/DependencyGraph.tsx（Skia + d3-force の力学配置）を height={240} で埋め込んでおり、GraphView と同じコンポーネント。表示条件は連結成分のノード数 > 1、ラベルはタスクの title、完了/スキップ済みは done 色、冗長な辺は破線（#387）、タップで /task/{id} へ遷移（view のみ）。mock もそれに寄せ、依存リストの下に「依存グラフ」ラベル付きで置いた。edit モードでも表示される（実装に !editing ガードはない）。
  • 補足説明は info ボタンに退避: 「時間固定を有効にすると…」のような説明文を常時表示のカードに置くと、読み終わった後もずっと縦を食う。ラベル横の i ボタン → popover に変えた。放棄しやすさ / 並列実行 / 並列受け入れ / 依存 (DAG) も同じ扱い。

v6: 現行実装からの退行を修正

v5 は現行 UI にある機能をいくつも落としていた。以下を復元した。

  • ステップの accordion（HabitStepEditor #390）: v5 は全展開の平坦カードで、3 ステップで約 2000px あった。折りたたみヘッダー（idx / タイトル / 時刻）に戻し、↑↓ 並び替えと削除確認ボタンも復元。
  • outlined 入力: 現行は react-native-paper の mode="outlined"。v5 の「下線だけ・右寄せ」はフィールド境界が読めず、実装よりも曖昧だった。枠 + フローティングラベルに戻した。
  • 放棄しやすさは Slider: 現行は step=0.25 の Slider。v5 の pulldown は実装と別物だった。
  • avg 最大化ボタンと window / sigma ヒント。
  • 依存の循環検出 UI: 循環する候補は disabled + 理由表示。
  • RedundantDepWarning（冗長な依存の警告）。
  • 並列タスク行、コストの実績表示、直近タスクの status。
  • Habit 本体設定の折りたたみ: v5 は静的な注意書きに置き換わっていたが、現行どおり開閉するセクションに戻した。

要確認

  • edit のヘッダーから ✓ / ✕ を外し、下部の sticky save bar に一本化。長いフォームでは下部バーが届きやすい。
  • view の真偽値を chip にしたことで、編集時は switch に切り替わる。視覚的な一貫性をどこまで保つか。
  • abandonability の日本語化は UI 全体（TaskAddView / HabitAddView など）に波及する。
  • avg 欄の書式ヒントは placeholder 化していない。入力値が空の場合のみ placeholder が表示される。
  • Habit の rrule 要約は「繰り返し」セクションに移動。長い RRULE の折り返しを実装で確認する必要がある。
  • Habit の step 依存は checkbox 羅列のまま。step 数が増えると見づらくなる。別途 DependencyGraph 埋め込みまたは tree 表示を検討。
