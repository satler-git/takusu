ポイント

  • 大きい 4x2 は進行中タスク＋次のタスク。1 週間（今日から 7 日先）までのタスクを最大 14 件まで表示。
  • 日付が変わるたびに「今日 / 明日 / M/d」の区切りを挿入。
  • アイテム間は透明な 4dp ディバイダーで隙間を確保。
  • 4x2 ウィジェットのパディングを 16dp に統一し、外径 28dp の角丸に対して配置を整える。
  • 時刻チップ＋タイトル＋緊急度ドットのコンパクトな一行アイテム。
  • 緊急度ドット: 赤 = must-do (a < 0.25)、黄 = caution (a < 0.5)、緑 = calm。
  • サイズが変わっても色・角丸・タイポグラフィのベースは同じ。情報量だけを絞る。

小さいサイズのパターン

同じ内容を 4x1 / 2x2 / 2x1 でそれぞれ最適な情報量に絞って表示。デザイン言語は維持する。

サイズ別表示ルール

  • 4x2: メイン widget。進行中タスク＋次のタスク最大 14 件、1 週間のホライズン内で日付区切り付き。
  • 4x1: 1 行で「進行中」または「次のタスク」のみ。時刻・タイトル・件数 chip。
  • 2x2: 縦型。進行中 or 次のタスク 1 件を大きく。残りは最大 3 件のミニリスト。
  • 2x1: 最小。ブランドアイコン＋ラベル＋タイトル＋時刻。余白は極力詰めない。

実装イメージ

  • レイアウト: mobile/modules/takusu-widget/android/src/main/res/layout/takusu_widget_4x2.xml / takusu_widget_4x1.xml / takusu_widget_2x2.xml / takusu_widget_2x1.xml
  • RemoteViews 内で日付を java.time で解析し、takusu_widget_date_header を動的に挿入。
  • ホライズンは WIDGET_DAYS_HORIZON = 7、サイズ別キャップは 4x2=14 / 2x2=3。
  • オーバーフロー行は takusu://tasks へ遷移。
