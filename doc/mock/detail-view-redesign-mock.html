DESIGN NOTES — TASK

ヘッダカード

背景は taskCardColor (must-do は赤系) で一覧と視覚接続。ステータスと並列ゲストをチップ表示。日付はスケジュールストリップに統合。

スケジュールストリップ

時間はテキスト羅列でなくトラック + now マーカー。「残り34分」等をチップ併記。

状態別 primary アクション

進行中→完了、スケジュール済→開始、未スケジュール→期限を設定。分割は独立した目立つボタン。

数量 = 実績 + ペースマーカー

バーが実績 (12/20)、▲ が時間経過から見た想定進捗 (62%)。枠内で今どこにいるか、遅れ/先行が一目で。

統計グリッドで密度2倍

abandonability はメタデータなのでヘッダでなくフラグ枠に小さく表示。

依存グラフは常時埋め込み

GraphView が最も分かりやすいので常に表示 (依存なしの場合のみ折りたたみ)。

完了時は重複させない

ヘッダはステータスと緑バーのみ。完了時刻・実績はアクション枠のバナーが担当。

編集 = 同じ画面でインライン

✎ でフォーム画面に遷移しない。タイトルはヘッダ内で入力、時間はストリップ内でピッカー起動、統計セルはその場で入力化。文脈と階層が保たれる。下部に保存バー。

DESIGN NOTES — HABIT

繰り返しは summary 表示を統合

独自のパターン可視化は分かりづらいため廃止。既存の summarizeRule (「平日 (月〜金)」) をヘッダの要約行に置き、時間枠と並べて表示。編集時はその行がそのまま RRULE ビルダー起動フィールドになる。

ヘッダ = 状態 + 要約1行 + 次回

関連情報を1行に束ねる。当日枠は大半がそうなる想定なので chip にしない。「次回発生」を目立たせる。

履歴ドット + 連続記録

直近14回をドットで表示 (緑=完了 / 赤=スキップ)。連続日数を併記。現行にはない情報。

ステップはタイムライン化

番号付き円と縦線で順序と依存を表現。編集時は各ステップがその場で入力化され、削除・追加ができる。

直近タスク・休止期間を高密度に

日付 (等幅) + ステータスドット + タイトルの密な行。休止期間は赤系で目立たせる。

無視される本体設定は表示しない

ステップ有効時、habit 本体の時間帯・コスト等は無視されるので表示しない。説明のみ残す。

編集 = 同じ画面でインライン

Task と同じく ✎ でフォーム画面に遷移しない。タイトル・繰り返し・ステップ・説明がその場で編集可能。下部に保存バー。
